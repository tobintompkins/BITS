# Attendance Reporting and Dashboard Polish

The private event attendance dashboard now provides a clearer reporting
experience for authorized church leadership.

- Branded summary cards show expected, present, checked-out, no-show, walk-in,
  and total-attended counts with readable labels.
- Staff can filter attendance by name or confirmation code, attendance status,
  and check-in source.
- Check-in sources display friendly names instead of database values.
- Clear resets all filters and reloads the first results page.
- Results are paged in groups of 25 with visible result and page counts.
- Authorized staff can download the complete event attendance CSV from a
  prominent action.
- Existing correction, no-show, check-out, and re-entry tools remain available.
- Server-side permissions and organization/event scoping remain authoritative.

No schema or migration change is required.
